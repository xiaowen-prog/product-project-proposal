# 通用产品立项报告 Skill

用六模块框架，把产品想法或调研材料整理成可决策的中文立项报告，支持 Idea 轻量模式与标准模式。

## 使用方法

本仓库是 AI Agent Skill，不是独立应用。将仓库作为一个技能文件夹放入支持 `SKILL.md` 的 Agent 的技能目录，或让 Agent 读取 [SKILL.md](SKILL.md) 后执行任务。具体加载方式以所用 Agent 为准。

```text
使用 $product-project-proposal，把下面的产品想法整理成 Idea 阶段立项报告：……
```

## 六个模块

1. 背景与问题
2. 目标用户与场景
3. 产品方案与 MVP
4. 可行性与资源
5. 商业价值与指标
6. 实施计划、风险与立项建议

SKILL.md 内含触发条件、证据与假设规则、可复制模板以及两个虚构示例。
